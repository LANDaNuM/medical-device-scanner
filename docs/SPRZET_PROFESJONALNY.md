## 🔧 Jak Symulować Urządzenia Medyczne

### 1. Symulacja BLE (Bluetooth Low Energy)

#### Opcja A: ESP32 (NAJTAŃSZA - ~50 PLN)

**Co to jest:**
- ESP32 to tani mikrokontroler z wbudowanym Bluetooth
- Możesz zaprogramować go jako symulator urządzenia medycznego

**Jak użyć:**
```python
# Przykład: Symulator glukometru BLE na ESP32
# (Kod Arduino/PlatformIO)

#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>

BLECharacteristic *pCharacteristic;
bool deviceConnected = false;

// UUID dla Glucose Service (standard medyczny)
#define SERVICE_UUID        "1808"
#define CHARACTERISTIC_UUID  "2A18"

void setup() {
  BLEDevice::init("Symulator Glukometru");
  BLEServer *pServer = BLEDevice::createServer();
  
  BLEService *pService = pServer->createService(SERVICE_UUID);
  pCharacteristic = pService->createCharacteristic(
    CHARACTERISTIC_UUID,
    BLECharacteristic::PROPERTY_READ |
    BLECharacteristic::PROPERTY_NOTIFY
  );
  
  pService->start();
  BLEAdvertising *pAdvertising = BLEDevice::getAdvertising();
  pAdvertising->addServiceUUID(SERVICE_UUID);
  pAdvertising->start();
}

void loop() {
  // Symuluj odczyty glukozy
  int glucose = random(70, 180); // 70-180 mg/dL
  pCharacteristic->setValue(glucose);
  pCharacteristic->notify();
  delay(5000);
}
```

**Koszt:**
- ESP32: ~50 PLN
- Kabel USB: ~10 PLN
- **RAZEM: ~60 PLN**

**Co możesz symulować:**
- ✅ Glukometr (Glucose Service)
- ✅ Pulsoksymetr (Heart Rate Service)
- ✅ Ciśnieniomierz (Blood Pressure Service)
- ✅ Wszystkie urządzenia BLE medyczne

---

#### Opcja B: Raspberry Pi (BARDZIEJ ZAAWANSOWANA - ~300 PLN)

**Co to jest:**
- Raspberry Pi może działać jako pełny symulator urządzenia medycznego
- Może symulować wiele urządzeń jednocześnie

**Jak użyć:**
```python
# Przykład: Symulator wielu urządzeń BLE na Raspberry Pi
# (Kod Python z biblioteką bluez)

import dbus
import dbus.exceptions
import dbus.mainloop.glib
import dbus.service
from gi.repository import GLib

class GlucoseService(dbus.service.Object):
    """Symulator glukometru BLE"""
    
    GLUCOSE_SERVICE_UUID = "1808"
    GLUCOSE_CHAR_UUID = "2A18"
    
    @dbus.service.method("org.bluez.GattCharacteristic1",
                         in_signature='a{sv}',
                         out_signature='ay')
    def ReadValue(self, options):
        # Symuluj odczyt glukozy
        glucose = random.randint(70, 180)
        return [glucose]
```

**Koszt:**
- Raspberry Pi 4: ~300 PLN
- Karta SD: ~30 PLN
- **RAZEM: ~330 PLN**

**Co możesz symulować:**
- ✅ Wiele urządzeń jednocześnie
- ✅ Kompleksowe scenariusze
- ✅ Sieć urządzeń medycznych

### 2. Symulacja WiFi (Urządzenia Sieciowe)

#### Opcja A: Raspberry Pi jako Serwer Medyczny

**Jak użyć:**
```python
# Przykład: Symulator serwera DICOM na Raspberry Pi
# (Kod Python z Flask)

from flask import Flask, jsonify
import random

app = Flask(__name__)

@app.route('/dicom/studies', methods=['GET'])
def get_studies():
    """Symuluj serwer DICOM"""
    return jsonify({
        "studies": [
            {
                "id": "STUDY001",
                "patient": "Jan Kowalski",
                "modality": "CT",
                "date": "2026-01-18"
            }
        ]
    })

@app.route('/hl7/patient', methods=['GET'])
def get_patient():
    """Symuluj serwer HL7"""
    return "MSH|^~\\&|HIS|HOSPITAL|LAB|20260118120000||ADT^A01|12345|P|2.5"

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=104)  # Port DICOM
```

**Koszt:**
- Raspberry Pi: ~300 PLN
- **RAZEM: ~300 PLN**

**Co możesz symulować:**
- ✅ Serwer DICOM (port 104)
- ✅ Serwer HL7 (port 5000)
- ✅ Urządzenia IoT medyczne
- ✅ Systemy szpitalne
